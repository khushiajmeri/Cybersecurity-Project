## Project Overview
This project demonstrates a web vulnerability assessment using **OWASP Zed Attack Proxy (ZAP)** on the TryHackMe platform.  
The goal was to configure a proxy, perform spidering and active scanning, and generate a report aligned with the **NIST Cybersecurity Framework (Detect & Respond)** functions.

## Tools & Technologies
- TryHackMe AttackBox  
- OWASP ZAP  
- Firefox Proxy Configuration  
- Linux Terminal  

## Methodology
1. Logged in to TryHackMe using FedUni email and launched the AttackBox.  
2. Configured OWASP ZAP as a local proxy on port 8081.  
3. Routed Firefox traffic through ZAP to capture requests.  
4. Performed **Spider** and **Active Scan** on the target web app.  
5. Generated an HTML vulnerability report and saved evidence screenshots.

## Results
- Scan completed successfully with **no high-severity vulnerabilities** found.  
- Confirmed correct ZAP setup and full scan workflow.  
- Produced report documentation for portfolio verification.


## Reflection
This project helped me gain hands-on experience with vulnerability assessment tools and better understand automated scanning, ethical testing, and the NIST CSF framework.  
It also strengthened my ability to document cybersecurity processes professionally.
